# ACP is bidirectional: clients own the environment while agents own the conversation

The **client** is the user-facing editor or UI: it launches a typical local agent, manages interaction and resources, and decides what the agent may access. The **agent** is the generative-AI program that works on code ([overview, L40–L42 and L59–L61](https://agentclientprotocol.com/protocol/v1/overview)). This is a trusted-model design, not a sandbox boundary: the editor exposes local files and MCP servers, while retaining controls over tool calls ([architecture, L5–L9](https://agentclientprotocol.com/get-started/architecture)).

The agent endpoint’s baseline requests are `initialize`, `session/new`, and `session/prompt`; authentication adds `authenticate`. Capability-gated requests include `session/load`, `session/list`, `session/resume`, `session/close`, `session/delete`, `session/set_mode`, `session/set_model`, `session/set_config_option`, and `logout`; `session/fork` exists only in the unstable schema ([meta.unstable.json](https://github.com/agentclientprotocol/agent-client-protocol/tree/b44babba0bbcd398fa36ee0545a6de9c147c67c0/schema)). The client sends the baseline `session/cancel` **notification** ([overview, L13–L38](https://agentclientprotocol.com/protocol/v1/overview)).

The client endpoint’s baseline request is `session/request_permission`. Advertised capabilities add `fs/read_text_file`, `fs/write_text_file`, the `terminal/*` family (`create`, `output`, `release`, `wait_for_exit`, `kill`), and `elicitation/create`. Agents send `session/update` notifications; clients send `elicitation/complete` for completed URL interactions ([overview, L62–L93](https://agentclientprotocol.com/protocol/v1/overview)).

ACP follows JSON-RPC 2.0: methods receive a `result` or `error`; notifications never receive either. Envelope keys follow JSON-RPC, ACP object keys are `camelCase`, and discriminator values are `snake_case` ([overview, L95–L111](https://agentclientprotocol.com/protocol/v1/overview)). One connection can multiplex several independent sessions ([architecture, L11–L19](https://agentclientprotocol.com/get-started/architecture)).
